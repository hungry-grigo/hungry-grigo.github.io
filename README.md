# SEO-оптимизация интернет-магазина на Tilda (кейс)

**Проект:** Мастерская «КоКо» — кокошники и русская одежда ручной работы  
**Сайт:** [koko-kokoshnik.ru](https://koko-kokoshnik.ru/)  
**Платформа:** Tilda + Tilda Store (185 товаров)  
**Моя роль:** Полный цикл SEO-оптимизации (техническое SEO, контент, аналитика, локальное SEO)  

---

## 🎯 Задача
Сайт молодой, SEO ранее не занимались. 75% трафика — мобильные устройства. 
Цели: сделать сайт видимым для поисковиков, внедрить микроразметку, ускорить загрузку, устранить дубли метатегов и настроить локальное SEO.

---

## 🛠 Что было сделано

### 1. Микроразметка Schema.org
Внедрены 7 типов разметки (Organization, LocalBusiness, Product, Offer, BreadcrumbList, FAQPage и др.) через HTML-код в HEAD Tilda. 
*Результат:* 9 элементов без ошибок в Rich Results Test на карточке товара.

### 2. Массовая оптимизация метатегов (185 товаров)
Через экспорт/импорт CSV и Google Sheets сгенерированы уникальные title и description для всех 185 товаров.
*Результат:* Убрано 104 дубля заголовков (стало 0).

### 3. Скорость загрузки (Core Web Vitals)
Сжаты hero-изображения в WebP, настроены preload и preconnect, оптимизированы JS-скрипты, сокращено количество товаров на главной.
*Результат:* LCP снизился с 10,8 сек до 2,1 сек. PageSpeed (mobile) вырос с 45 до 66.

### 4. Мобильная адаптация и 152-ФЗ
Переработан мобильный UX (H1, меню). Чек-бокс согласия на обработку ПДн снят по умолчанию и обязателен для отправки формы (JS-guard).

### 5. Семантика и локальное SEO
Собрано ~600 чистых запросов через Python. Настроена карточка в Яндекс.Бизнесе (удалены дубли, добавлены фото/видео).

## 💡 Ключевые решения
* **Schema.org через JS** — без правок в ядре Tilda, легко откатить.
* **Два hero-блока** — быстрый LCP на мобильных, качество на ПК.
* **CSV-массовое обновление** — 185 товаров за 1 импорт.
